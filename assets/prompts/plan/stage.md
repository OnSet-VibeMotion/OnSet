## {{STAGE:plan}}：按语义拆分镜头

根据 `transcription-production.srt` 做粗粒度分镜：

- 一个镜头可以包含一条或多条连续字幕。
- 合并依据是同一主题、同一因果关系或同一视觉概念，不按固定字幕条数机械切分。
- 每个镜头对应一个连续时间区间。
- 所有镜头按顺序首尾相接，完整覆盖从节目第 0 帧到最终帧的总跨度。
- 无文字空白并入前一个镜头作为停顿、收尾或转场；很长的空白可以单独成为静默/转场镜头。
- 镜头时长不要手算：分镜只决定「每个镜头从哪条字幕或哪个短语开始、切在空白的哪一侧」，帧号由 `scene_cues()` 推出。

把分镜写成 `production/scene-plan.json`，字段名固定（`scene_cues()` 严格解析，未知字段直接报错）：

```json
{
  "schema": 1,
  "look": {"background": "#0F1720", "ink": "#F5F1E8", "accent": "#F2B134"},
  "scenes": [
    {"id": "scene-001", "dir": "scenes/scene-001", "chapter": "问题", "visual_role": "语境", "summary": "开场提出问题"},
    {"id": "scene-002", "dir": "scenes/scene-002", "chapter": "问题", "first_subtitle": 5, "visual_role": "机制",
     "motion_effects": ["motion-prompt:007"],
     "handoff": {"device": "carry", "bridge": "左上角的计数器，宽 160、高 64，停在 42"}},
    {"id": "scene-003", "dir": "scenes/scene-003", "chapter": "机制", "first_phrase": "p-07", "cut": "mid_gap", "visual_role": "证据",
     "handoff": {"device": "push_in", "bridge": "画面被计数器的琥珀色表面铺满，中心一个直径 24 的深色圆点"}},
    {"id": "scene-004", "dir": "scenes/scene-004", "chapter": "回忆", "first_subtitle": 14, "visual_role": "语境", "film_style": "来源/目录名",
     "handoff": {"device": "push_in", "bridge": "桌上相框里的旧照片铺满画面，照片中央一扇亮着灯的窗", "style_shift": "window"}}
  ]
}
```

- 除第一个镜头外，每个镜头写 `first_subtitle`（`transcription-production.srt` 里的字幕序号，从 1 开始）或 `first_phrase`（`phrase-timeline.json` 的 `phrase_id`），只写一个。
- `cut` 决定切点落在空白哪一侧：缺省 `next_start`（空白并入前一个镜头）、`prev_end`（空白并入本镜头）、`mid_gap`（切在空白正中）。很长的空白要单独成为静默或转场镜头时，给它一个镜头，锚点写空白后的第一条字幕。
- `dir` 的顺序必须与 `scenes/` 下镜头目录的字典序一一对应。
- `look` 照抄 `treatment.md` 的全片配色：`background`、`ink`、`accent` 必填，`surface`、`accent_2` 可选。
- `chapter` 照抄 `treatment.md` 的章节名，要写就每个镜头都写；相邻镜头 `chapter` 不同即章节交界。
- `handoff` 写在交界后面那个镜头上，说明从上一镜头怎么接进来；章节交界与风格交界必填，章节内有持续物件跨过交界时也写上。
- `film_style` 只在镜头不用默认风格时写（见{{STAGE:intake}}「段落换风格」）；风格交界的 `handoff` 还要写 `style_shift`，风格相同的交界不能写。
- `motion_effects` 可选，本镜头核心表达所需的标志性动效数组（支持简写如 `"005"` 或完整 `"来源:id"`，单镜最多 3 条）；由 `scene_cues()` 校验后写入 `scene.json`，渲染时片场自动展开动效配方并联动配套插件技能。

### 镜头交接

镜头各自渲染、互相看不到，两个镜头接不接得上只取决于它们是否照同一份约定画出同一帧。`handoff` 就是这份约定：`scene_cues()` 把它原样写进两侧镜头的 `timing` 块，两个渲染提示词拿到的是同一段话，并告诉各自可用于交接动作的空档帧。没写 `handoff` 的交界是硬切。

章节交界要和章节内的切换一样自然：不要给章节交界套一个统一的擦除或闪白，而是从上一章最后的画面里找一个东西把观众带进下一章。`device` 取以下之一：

| 手法 | 做法 | 适合 |
|---|---|---|
| `carry` 接力 | 同一个物件跨过交界，位置、大小、颜色和状态两侧一致，下一镜头接着让它变化 | 持续物件贯穿两章 |
| `match` 形状匹配 | 上一镜头某元素末帧的轮廓、位置和大小，与下一镜头一个不同元素首帧的完全重合（圆点变成地球、进度条变成时间轴） | 两章讲的是同一件事的两个层面 |
| `push_in` 推进穿越 | 镜头推进到上一镜头某个元素内部，它的表面铺满画面，成为下一镜头的底面 | 从整体进入细节、从现象进入原因 |
| `flood` 色块铺满 | 上一镜头某元素扩张到铺满画面，它的颜色成为下一镜头开场的底色 | 情绪或结论落定后翻开新一章 |
| `pan` 平移续接 | 同一张底面朝一个方向平移，上一镜头内容移出、下一镜头内容从另一侧移入 | 并列、对比、时间推进 |
| `settle` 退回底色 | 上一镜头语义元素退场，只剩全片底色和一个保留元素，下一镜头从它长出 | 节奏放缓、换一口气 |

- `bridge` 只写交界那一帧：哪个物件、在画面哪个位置、多大、什么颜色和状态、底色是什么，不超过 200 字。两个渲染器都要照它画出这一帧，写得含糊就接不上。
- 相邻两个章节交界不得用同一种手法，`scene_cues()` 会拒绝；整片也不要让一种手法占大多数。
- 交接动作放在字幕之间的空档里：章节交界的切点用 `cut` 落在空白里，前后各留出约 0.3 秒，交接动作才不会压住正在读的字。

### 风格交界

两侧镜头的风格不同时，光让画面接上还不够：画法（笔触、材质、线条、配色、字体）也要在画面里一点点换过去，不能在交界帧上突变。`style_shift` 取以下之一，并且只能配表里写的 `device`：

| 手法 | 做法 | 谁来换画法 | 配 `device` |
|---|---|---|---|
| `morph` 材质转化 | 交接物件不换，换的是它的画法：交界帧两侧都按上一镜头的风格画它，下一镜头开场用 0.5–1.5 秒让它的笔触、材质与配色变成新风格，周围画面跟着一层层换过去（线稿被填上颜料、墨迹晕成油彩、像素块柔化成笔触） | 下一镜头开场 | `carry`、`match`、`settle` |
| `window` 画中画推入 | 上一镜头末段，画里某个物件（屏幕、窗、书页、画框、镜面、水面）里出现按下一风格画的画面，镜头推进到它铺满 | 上一镜头末段 | `push_in` |
| `sweep` 画内揭开 | 画里的一样东西扫过画面（翻过的书页、漫开的颜料或墨水、扫过的光带、拉过的幕布），扫过的地方换成新风格 | 两侧各做一半 | `flood`、`pan` |
| `match_cut` 形状匹配切 | 两侧各按自己的风格画，靠交接物件的轮廓、位置、大小、朝向与主色完全一致把眼睛带过去 | 不换，靠形状 | `match`、`carry` |

- 两个渲染提示词都会带上「风格切换」段：对方的风格在哪、用哪种手法、自己负责哪一段。负责按对方风格画的一侧会拿到对方 `STYLE.md` 的路径，只取外观、材质、笔触与配色。
- 选手法看两种风格差多远：材质相近（水彩与油画、线描与版画）用 `morph` 最自然；差得远（像素与水墨、写实与扁平图形）用 `window` 或 `sweep`，让新风格先在一个框里或一道边界后面出现；两种风格都有清楚的轮廓时可以用 `match_cut`。
- `bridge` 要写到能让两个渲染器各自画出同一帧：交接物件是什么、在哪、多大、什么状态，以及交界帧上它是按哪一侧的风格画的。
- 风格交界禁止整画面叠化、淡出淡入黑场或白场、与画面无关的擦除、故障或闪白。整片复查时逐一看风格交界的 `seam-NN.png`：过渡途中每一帧都要像同一件东西在变，看起来像两张画面叠在一起的就重渲染负责换画法的那一侧。

同时写 `production/scene-plan.md` 给人审阅：每个镜头的字幕范围、视觉角色、要证明或解释的台词。
